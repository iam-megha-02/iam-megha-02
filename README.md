### 🔭 Featured Projects

**[ThyBot](https://github.com/iam-megha-02/ThyBot)** — [Live Demo](https://thybot-2026.streamlit.app/)
A thyroid health assistant using retrieval-augmented generation. Combines dense embeddings, BM25, and reciprocal rank fusion for retrieval, layered deterministic + semantic guardrails for safety, and a 100-case evaluation set with a held-out test split.
`FAISS` `BM25` `Groq API` `Streamlit`

**[AskYourDB](https://github.com/iam-megha-02/AskYourDB)** — [Live Demo](https://askyourdb-bjuekrtwwfgq5dtacgswyy.streamlit.app)
A natural-language-to-SQL assistant with a query inspector, three layered safety guardrails against adversarial prompts, and a 20-case evaluation harness with independently verified ground truth.
`LangChain` `SQLite` `Groq API` `Streamlit`

**[GraphSonix](https://github.com/iam-megha-02/GraphSonix)** — [Live Demo](https://graphsonix-uhplphnz8ad6fdhnado2rk.streamlit.app/)
Turns graph structure into music. Node2Vec embeddings implemented from scratch (biased random walks + Word2Vec), paired with a custom audio synthesis engine including hand-written WAV encoding.
`Python` `NetworkX` `Gensim` `NumPy`
